# Workspace tables and plots

A workspace creates the tables and plots used in pyGSTi reports. These notebooks show how to use those components individually:

- [Creating workspace tables and plots](WorkspaceFigureExamples) builds a workspace, displays figures, and exports them to files.
- [Switchboards](Switchboards) adds controls that select between data sets, models, or other figure inputs.
