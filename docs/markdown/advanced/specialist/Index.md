# Specialist protocols

These protocols estimate particular properties of a device. Each notebook provides its own worked example, so you can start with the quantity you want to measure:

- [Robust phase estimation](RobustPhaseEstimation.md) estimates single-qubit rotation angles from circuits designed for that purpose.
- [Parity benchmarking](ParityBenchmarking) measures the weight-X disturbance between a reference and a test dataset, illustrated with a four-qubit parity check.

Related methods are grouped with their protocol families: [GST with richer device models](../../guides/gst/RicherDeviceModels) covers qutrits, leakage, and time-dependent operations; [Judging GST fits](../../guides/gst/JudgingTheFit) includes robust GST with a TVD budget; and [Randomized benchmarking](../../guides/rb/HowRBWorks) includes SU(2) qudit RB.
