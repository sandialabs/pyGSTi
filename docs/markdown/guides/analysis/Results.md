# Results and reporting

A protocol's results contain its estimates and the data used to produce them. [Inspecting GST results](InspectingResults) shows how to access fitted models, gauge-optimized estimates, and confidence-region objects in a GST results object.

- [Report generation](Reports) turns results into an interactive report.
- [Metrics](Metrics) computes measures of gate error and model differences.
- [Gauge freedom](GaugeFreedom) explains how the choice of gauge affects model comparisons and demonstrates gauge optimization.
- [Error bars](ErrorBars) computes uncertainty estimates.
- [Model testing](ModelTesting) compares a specified model with data without fitting a new model.

If you're unsure whether a GST fit is acceptable, start with [Judging GST fits](../gst/JudgingTheFit).
