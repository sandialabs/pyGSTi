# Drift characterization

Drift analysis uses the timing of experimental outcomes to detect changes in a device's behavior. Start with the notebook that matches your data:

- [Timestamped data](TimestampedData) constructs data sets that retain time information and demonstrates how to access it.
- [Detecting and characterizing drift](DriftAnalysis) analyzes simulated time-stamped outcomes, inspects power spectra, and estimates probability trajectories.

If you have separate batches of counts for the same circuits rather than a time series, use [Comparing datasets](ComparingDataSets). To fit a time-dependent gate model with GST, see [Time-dependent GST](../gst/TimeDependentGST).
