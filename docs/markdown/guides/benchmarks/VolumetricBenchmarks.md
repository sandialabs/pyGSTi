# Volumetric benchmarking

Volumetric benchmarks compare performance across circuit widths and depths. Choose between mapping performance over a family of circuit shapes and estimating fidelity for a particular circuit:

- [Running volumetric benchmarks](VolumetricBenchmarkExamples) builds direct-RB and mirror-circuit experiments, summarizes their data, and plots capability regions.
- [Mirror circuit fidelity estimation](MirrorFidelityEstimation) estimates the process fidelity of a supplied circuit mapped to U3 and controlled-X gates. The example uses Qiskit.

For protocols that report an error rate from a decay curve, see [Randomized benchmarking](../rb/HowRBWorks).
