# Judging GST fits

Fit statistics quantify how well an estimated model agrees with the data. [Reading GST fit statistics](FitStatistics) explains the likelihood-ratio statistic, degrees of freedom, and reported significance, with a worked fit you can inspect.

- [Bad fits](BadFits) provides checks for optimizer convergence, data consistency, and model assumptions.
- [Robust GST with a TVD budget](RobustGST-TVD) works through allowing additional model discrepancy and interpreting the resulting budget.

For the surrounding report and its plots, see [Report generation](../analysis/Reports). For choosing an optimization protocol, return to [Running GST](RunningGST).
