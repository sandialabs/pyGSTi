# Core objects

These chapters explain the model components, conventions, simulation engines, and reporting objects used by pyGSTi's protocols. Use them to customize an analysis, inspect how its objects work, or extend the library.

- [Operators](operators/Index) covers operation, state-preparation, and measurement classes, their parameterizations, and custom implementations. For complete device models, start with [Defining models](../models/Index).
- [Bases and state spaces](bases/Index) explains matrix-basis conventions, subsystem labels, and state-space structure.
- [Forward simulators](simulation/Index) covers computing circuit probabilities, stabilizer simulation, and numerical and symbolic error-generator propagation.
- [Low-level GST](lowlevel/Index) provides direct access to fitting and gauge-optimization algorithms for analyses assembled below the protocol interface.
- [Workspace tables and plots](figures/Index) shows how to create individual report components and add controls that select their inputs.

For analyses organized around an experiment design and a protocol, see the [Characterization guides](../guides/Index).
